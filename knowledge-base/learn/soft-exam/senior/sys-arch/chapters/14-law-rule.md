# 法律法规

- 考情分析
    - 选择，3分
        - 著作权归属、侵权判定、其他法规
- 著作权法
- 软件著作权
- 专利权、商标权、秘密

## 著作权法

- 著作权包括
    - 发表权
    - 署名权
    - 修改权
    - 保护作品完整权
        - 改编反原著内容，就是违反完整权
    - 使用权
    - 使用许可权
    - 获取报酬权
    - 转让权
        - 即以复制、表演、播放、展览、发行、拍摄电影、电视、录像
        - 或者改编、翻译、注释、编辑等方式使用作品的权利
        - 以及许可他人以上述方式使用作品
        - 并由此获得报酬的权利
- 保护期限
    - 作者的署名权、修改权、保护作品完整权的保护期限不受限制
    - 公民的作品
        - 其发表权、使用权、获得报酬权的保护期限为作者终生以及死后50年，截止死后第50年的12月31日
        - 合作作品
            - 气质到最后死亡的作者死后50年
    - 法人或其他组织的作品
        - 著作权（署名权除外）由法人或其他组织享有的职务作品
        - 其发表权、使用权、获得报酬权保护期限为50年，截止于首次发表后50年
        - 但作品自创作完成50年未发表的，著作权法不再保护
- 著作权人的确定
    - 合作开发
        - 对于由两个及以上的开发者或组织
        - 合作开发的软件
        - 著作权的归属依据合同约定确定
        - 如无合同，则共享著作权
        - 若合作开发的软件可以分割使用
        - 那么开发者对自己开发的部分单独享有著作权
        - 可以在不破坏整体著作权的基础上行使
    - 职务作品
        - 一般职务作品（艺术作品类）
            - 作者享有著作权，单位优秀享有使用作品的权利
        - 特殊职务作品（技术作品类）
            - 著作权归单位
    - 软件职务开发
        - 如果开发者在单位或组织中任职期间，所开发的团建符合以下条件
        - 则软件著作权归单位或组织所有
            - 针对本职工作中明确规定的开发目标所开发的软件
            - 开发出的软件属于从事本职工作活动的结果
            - 使用了单位或组织的资金、专用设备、未公开的信息等物质、技术条件
                - 并由单位或组织承担责任的软件
    - 委托开发
        - 普通委托
            - 如果是接受他人委托而进行开发的软件
            - 其著作权的归属应由委托人与受委托人签订书面合同约定
            - 如没有签订合同，或合同中未规定的
            - 则著作权归受托人享有
        - 国家委托
            - 由国家机关下达任务开发的软件
            - 著作权的归属由项目任务书或合同规定
            - 如未明确规定
            - 其著作权归任务接受方所有

## 软件著作权

- 范围
    - 对软件著作权的保护知识针对计算机软件和文档
    - 并不包括开发软件所用的思想、处理过程、操作方法、数学概念等
- 包括
    - 发表权
    - 署名权
    - 修改权
    - 复制权
    - 发行权
    - 出租权
    - 信息网络传播权
    - 翻译权
    - 使用许可权
    - 获得报酬权
    - 转让权
- 保护期限
    - 软件著作权自软件开发完成之日起生效（不需要发表）
    - 著作权属于公民
        - 保护期限为作者终生及死后50年
        - 对合作开发的，以最后死亡作者为准
    - 著作权属于单位
        - 保护期限为首次发表后50年
        - 50年内未发表的，不予以保护
        - 单位变更、终止后，其著作权由承受其权利义务的单位享有
- 所有人的权利
    - 根据使用的需求，将该软件安装到设备中
    - 制作复制品的备份，以防止复制品损坏，但复制品不得转给其他人使用
    - 根据实际环境，对其进行功能、性能等方面的修改稿
        - 但未经软件著作权人许可，不得向任何第三方提供修改后的软件
    - 如果使用者只是为了学习、研究软件中的设计思想、原理
        - 而以安装、显示和存储软件等方式使用软件
        - 可以不经软件著作权人的许可，不向其支付报酬

## 专利权、商标权、秘密

- 专利权（需要续年费才保护）
    - 包括
        - 发明、实用新型、外观设计三种
    - 判定归属
        - 一份专利申请文件只能就一项发明创造提出专利申请
        - 一项发明只授予一项专利
        - 同样的发明申请专利，则按照申请时间的先后决定授予给谁
        - 若同一日申请，则应当在收到通知后自行协商确定申请人
    - 保护期限
        - 发明专利权20年
        - 实用新型、外观设计专利权为10年
        - 均从申请日起计算
        - 申请日，指向国务院专利行政主管部门提出专利申请之日
    - 专利权人的义务
        - 在保护期内
        - 专利权人应该按时缴纳年费
        - 在专利权保护期限内
        - 如果专利权人没有按规定缴纳年费
        - 或以书面声明放弃其专利权
        - 专利权可以在期满前终止
    - 发明专利的归属
        - 职务发明
            - 执行本单位的任务或者主要是利用本单位的物质技术条件所完成的发明创造为职务发明创造
            - 应该归属于单位
            - 申请被批准后，该单位即为专利权人
            - 员工离职后一年内做出的专利技术，**
            - 其内容与原单位本职工作、分配的任务具有较强关联性的
            - 认定属于职务发明创造
        - 非职务发明
            - 非职务发明创造，盛情专利的权利属于发明人或者设计人
            - 被批准后，该发明人或设计人为专利权人
        - 合作发明
            - 两个及以上的单位或废人合作完成的发明创造
            - 除另有协议的以外
            - 申请专利的权利属于共同完成的单位或个人
            - 被批准后，申请的单位或个人未专利权人
        - 委托发明
            - 一个单位或个人接受其他主体委托所完成的发明创造
            - 除另有协议的以外
            - 申请专利的权利属于完成的单位或者个人
            - 被批准后，申请的单位或个人为专利权人
- 商标权
    - 范围
        - 在同一种商品或者类似的商品上
        - 果蔬行业和电子行业，都是苹果，这就不构成侵权
    - 定义
        - 两个或以上的申请人，在同一种商品或者类似商品上
        - 分别以相同或者近似的商标在同一天申请注册的
        - 各申请人应当受到商标局通知之日其30日内提交其申请注册前在先试用该商标的证据
            - 同日使用或均为使用的
                - 收到通知30日内自行协商，将书面协议报送商标局
            - 不愿协商或协商不成的
                - 抽签决定，其他人驳回
            - 已经通知单位参加抽签的
                - 视为放弃申请
                - 商标局应书面通知未参加抽签的申请人
    - 有效期
        - 注册商标的有效期为10年，自核准注册之日起计算
        - 有效期满，需要继续使用的，应期满前6个月内申请续展注册
        - 未能提供申请的，可以给予6个月宽限期
        - 宽限期仍未生情的，注销注册商标
        - 每次续展注册有效期为10年
- 商业秘密
    - 必备特性
        - 未公开性
        - 实用性
        - 保密性
    - 期限
        - 商业秘密永久保护，但缺少了上述特性之一，则丧失保护
        - 比如
            - 员工泄密后，失去保护，员工会被处理

## 知识点补充

- 知识产权属于民法的范畴
- 专利要求书说明了专利保护范围
- 软件著作权需要提供的鉴别材料是程序和文档
