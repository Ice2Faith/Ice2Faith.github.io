## 网络与通信基础知识

- 计算机网络分类
    - 分类
        - 总线型
        - 环形（令牌环网）
        - 星形（集线器）
        - 树形（交换机）
        - 网状（路由器）
- OSI参考模型
    - 分层
        - 应用层（报文）
            - 提供OSI用户服务，即确定进程之间通信的性质
            - 以满足用户需要以及提供网络与用户应用软件之间的接口服务
            - 如事务处理程序、电子邮件、网络管理程序
        - 表示层（报文）
            - 为应用层进程提供能解释所交换信息含义的一组服务
            - 即将要交换的数据从适合于某一用户的抽象语法转换为适合于OSI系统内部使用的传送语法
            - 提供格式化的表示和转换数据服务
            - 数据的压缩、解压缩、加密、解密等由本层负责
            - 序列化报文
        - 会话层（报文）
            - 为批次合作的表示层实体提供建立、维护和结束会话连接的功能
            - 完成通信进程逻辑名称名称和物理名称的对应
            - 提供会话管理服务
            - 本层不参与具体传输，只提供访问验证、会话管理等服务
            - 验证报文会话
        - 传输层（报文）
            - 为会话层实体提供透明、可靠的数据传输服务
            - 保证端到端的数据完整性
            - 选择网络层能提供最适宜的服务
            - 提供建立、维护、和拆除传输连接功能
            - 【注意】
                - 以上这4层均为报文
        - 网络层（包，路由器）
            - 为传输层实体提供端到端的交换网络数据的功能
            - 使得传输层拜托路由选择、交换方式、拥塞控制等网络传输细节
            - 可以为传输层实体建立、维持、拆除一条或多条通信路径
            - 对网络传输中发生的不可恢复的差错予以报告
            - 本层主要任务是路由选择，传输单位是包
        - 数据链路层（帧，交换机）
            - 在两个相邻节点间的线路上无差错的传送以帧为单位的数据
            - 并进行流量控制
            - 本层要负责建立、维持、释放数据链路的连接
            - 如果接收方检测到有差错，会要求发送方重发
        - 物理层（位）
            - 提供为建立、维护。拆除物理链路所需的机械、电器、功能和规程特性
            - 提供有关在传输介质上传输非结构的位流机物理链路故障检测指示
            - 物理层的任务是为上一层提供一个物理连接，单位是位
- 数据通信的计算
    - 字节
        - 8bit=1Byte
    - 码元
        - 1个码元就是一个脉冲信号
        - 一个脉冲有可能携带1bit、2bit、4bit等数据量
        - 1bit码元种类为2（0，1），2bit码元种类为4，以此类推
    - 码元传输速率（波特率）
        - 单位是Baud,1波特表示数字通信系统每秒传输1个码元
    - 数据传输速率（比特率）
        - 单位是bps或b/s
        - 表示单位时间内传输的bit位数量
    - 信道
        - 是信息传输的通道
    - 信道容量
        - 就是信道的最大传输速率，又叫信道带宽，单位Hz
    - 奈奎斯特定理（无噪声环境，理想环境）
        - B=2W
        - R=B*log2^N
        - B: 码元速率Baud
        - W: 信道带宽Hz
        - R: 数据传输速率bps或b/s
        - N: 码元种类
    - 香农定理（有噪声环境，非理想环境）
        - C=W*log2^(1+S/N)
        - W: 信道带宽Hz
        - C: 极限数据速率
        - S/N: 信噪比
        - 一般用db来表示，分贝是可测量的，用来计算信噪比
        - db=10*log10^(S/N)
    - 奈奎斯特取样定理
        - 数模转换的无失真传输极限
        - 若要对一个最高频率为F(max)的连续信号进行采样
        - 并无失真地还原原始信号，则F(s)必须满足
        - F(s)>=2*F(max)
        - F(max): 信号中存在的最高频率成分，单位Hz
        - F(s): 采样频率，单位Hz,即每秒采用点数

## TCP/IP协议族

- 概述
    - TCP/IP模型
        - 事实上的网络标准协议，采用5层网络模型
            - 应用层
                - 对饮OSI模型的应用层、表示层、会话层
            - 传输层
            - 网际层（网络层）
            - 网络接口层（数据链路层）
            - 物理层（硬件层）
        - 主要功能有
            - 逻辑编址
            - 路由选择
            - 域名解析
            - 错误检测
            - 流量控制
            - 对应用程序的支持
        - 主要TCP/IP协议
            - 数据链路层、物理层
                - Etherent IEEE 802.3
                - FDDI
                - Token-Ring IEEE 802.5
                - ARCnet
                - PPP/SLIP
            - 网络层
                - IP（核心）
                - ICMP
                - ARP
                - RARP
            - 传输层
                - TCP
                - UDP
            - 应用层
                - TCP传输的
                    - HTTP
                        - 超文本传输协议
                    - FTP
                        - 文件传输协议
                    - Telnet
                        - 远程登录协议
                    - SMTP
                        - 电子邮件协议
                - UDP传输的
                    - NFS
                        - 网络文件服务协议
                    - SNMP
                        - 网络管理协议
                    - DNS
                        - 域名解析协议
                    - OSPF
- IP协议
    - 将上层数据、或同层其他数据封装到IP数据报中
    - 将数据报传送到最终目的地
    - 为使数据能在链路层上传输，对数据分段
    - 确定数据报到达其他网络中的目的地址的路径
    - 格式
        - IP数据报
        - 源地址、目标地址
- ARP与RARP
    - ARP
        - 将IP地址转换为MAC物理地址
        - 运行
            - ARP广播，是自己的IP，就单播答复，形成对应关系
            - 不再同一个局域网，就交给路由器进行路由
    - RARP
        - 将MAC物理地址转换为IP地址
- TCP与UDP
    - TCP
        - 为应用层提供一个可靠的、面向连接的、全双工的数据传输服务
        - 特点
            - 超时重发、接收确认
    - UDP
        - 为应用层提供一个不可靠的、无连接的协议，主要用于保证数据间通信的效率
- ICMP协议
    - 用于在主机、路由器之间传递控制信息
    - 错误报告控制信息
    - 控制信息指网络通不通、主机是否可达、路由是否可用等
    - 报文类型
        - 差错报文
            - 0，回显应答，ping命令
            - 3，终点不可达
            - 4，源站抑制
            - 5，路由重定向
            - 11，时间超时
            - 12，参数问题
        - 询问报文
            - 8，10，回送请求或应答
            - 13，14，时间戳请求或应答

## 常见网络设备与IP地址

- 交换机（帧）
    - 二层交换机（以太网交换机）
        - 工作在数据链路层，用于隔离冲突域
        - 每个接口属于一个冲突域
        - 一个交换机属于一个广播域
        - 根据MAC地址转发数据帧
    - 工作原理
        - 主要基于其内部MAC地址表
        - 表记录了网络中所有MAC地址与交换机各个端口的对应信息
        - 当交换机收到数据时
        - 会检查数据帧的目的MAC地址
        - 然后根据MAC地址表将数据从目的主机所在的接口转发出去
    - MAC地址表建立
        - 通过广播，目标MAC主机进行单播响应，这样就确定了
        - 哪个MAC对应哪个端口
- 路由器（包）
    - 工作在网络层
    - 接口隔离广播域
    - 路由器通过路由协议 学习到达每个目的地址的路径形成路由表
    - 根据路由表相关路由条目，寻找最优路径
    - 根据下一条地址将数据包发送出去
    - 路由表建立
        - 定期将自己的IP发送给所有邻居
        - 这样就知道，哪个端口对应哪个IP
- IP地址
    - 这里说的是IPV4
    - 分类
        - A类地址
            - 1.0.0.0~127.255.255.55
            - 子网掩码：255.0.0.0
        - B类地址
            - 128.0.0.0~191.255.255.255
            - 子网掩码：255.255.0.0
        - C类地址
            - 192.0.0.0~223.255.255.255
            - 子网掩码：255.255.255.0
        - D类地址（组播）
            - 224.0.0.1~239.255.255.254
        - E类地址（保留）
            - 240.0.0.0~255.255.255.255
    - 同网段判断
        - 只需要计算IP地址位与上子网掩码是否相同即可
        - 也就是IP地址的2禁止表示对应的子网掩码有效位的二进制位是否一致

## 网络服务

- HTTP
    - 超文本传输协议
    - Hyper Text Transfer Protocol
    - 定义了Web服务器和Web浏览器之间通信的语言
    - 相互之间发送超文本标记语言HTML格式的文件
    - 基于TCP进行传输，端口是80
    - HTTPS是基于TLS/SSL的安全传输的HTTP协议，端口是443
- DNS
    - 域名解析服务
    - Domain Name Server
    - 提供了将域名转换为IP地址的服务
    - 使得用户只需要记住域名即可访问网址的能力
    - 基于UDP进行传输，端口为53
    - 工作模式
        - 递归查询
            - 被查询的主机，没有查询到的话，向下一级主机继续查询
        - 迭代查询
            - 被查询的主机，没有就直接返回建议去其他主机查询，自己的工作就完成了
- Telnet
    - 远程登录协议
    - 提供了允许连接远程服务器进行使用远程主机的能力
    - 基于TCP传输，端口为23
- SMTP
    - 简单邮件传输协议
    - Simple Message Transfer Protocol
    - 描述电子邮件传输格式和方法的，缺点是只能传送文本
    - 不能传送费ASCII码文本和非文字性附件
    - 后来使用MIME进行邮件扩充协议
    - 使用PEM增强邮件私密保护协议
    - SMTP使用TCP，用于发送，端口25
    - POP3使用TCP，用于接收，端口110
- WWW
    - 万维网服务
    - World Wide Web
    - 专用于BS服务的一组服务的总称
    - 包括HTTP、Web服务器、Web浏览器、HTML、URL等
- FTP
    - 文件传输协议
    - File Transfer Protocol
    - 基于TCP
    - 21端口，用于传输命令和参数
    - 20端口，用于传输文件
- DHCP
    - 动态主机配置服务
    - Dynamic Host Configuration Server
    - 基于UDP，服务端67端口，客户端68端口
    - 报文类型
        - discover,客户端广播寻找可用服务器
        - offer,服务端单播应答客户端，携带IP地址参数
        - request,回应收到的第一个服务，确认选择
        - ACK，服务端应答客户端确认可以分配
        - NAK，服务端应答无法分配
        - release,客户端不再使用，单播通知服务端
        - decline,客户端收到ACK之后，发现IP地址冲突，则告知服务端
