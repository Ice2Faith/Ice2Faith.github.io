## 计算机性能评价

- 计算机性能指标
    - 主要指标
        - 时钟频率（主频）
            - CPU的速度
            - 外频
                - CPU跟总线的同步速度
            - 主频=外频*倍频
        - 运算速度
        - 运算精度
        - 内存的容量
        - 存储器的存取周期
        - 数据处理速率（PDR）
        - 吞吐率
        - 各种响应时间
        - 各种利用率
    - RASIS特性
        - 可靠性（Reliability）
        - 可用性（Availability）
        - 可维护性（Serviceability）
        - 完整性（Integrity）
        - 安全性（Security）
- 性能计算
    - 时钟频率法
        - CPU主频越高、速度越快
        - 主频：每秒产生的时钟信号数量
        - 时钟周期：CPU完成一个基本动作的时间
            - 也就是主频的倒数
        - 指令时钟周期数（CPI）：执行一条指令所需要的时钟周期数
    - 指令执行速度法
        - 假发指令的执行速度来衡量计算机的执行速度
        - MIPS
            - 每秒执行的指令条数（以百万条为单位）
        - MFLOPS
            - 每秒执行的浮点运算指令条数（以百万条为单位）
        - 举例
            - 主频为1GHz,CPI为2.24，则MIPS=IPS*百万=主频/CPI*百万
    - 等效指令速度法（吉普森法）
        - 统计程序中各类指令所占比例，进行加权平均折算
        - 即T=1到n上求和（占比i*时间i）
- 性能设计
    - 性能调整
        - 当系统性能降到最基本的水平时
        - 性能调整由查找和消除瓶颈组成
        - 在开始性能调整之前
        - 准备工作由识别约束、指定负载、设置性能目标
        - 人话
            - 性能调整的目的就是在保证业务正常运行的约束下
            - 执行特定的业务流程负载
            - 达到设定的性能目标的过程
    - 阿姆达尔解决方案
        - 加速比=不增强的完成时间/使用增强的完成时间
        - 人话
            - 也就是未加速时的时间，与加速后的时间的比值，即为加速比
            - 就是性能提升了多少倍
- 性能评估方法
    - 基准测试程序
        - 把应用程序中用的最多、最频繁的那部分核心程序作为评价计算机性能的标准程序
        - 叫做，基准测试程序
        - 大致包括
            - 整数测试程序 Dhystone
            - 浮点测试程序 Linpack
            - Whestone 基准测试程序
            - SPEC 基准测试程序
            - TPC 基准程序
        - 评价准确度依次递减为
            - 真实程序
            - 核心程序
            - 小型基准程序
            - 合成基准程序
    - WEB 服务器的性能评估
        - WEB服务器的性能指标有
            - 最大并发连接数
            - 响应延迟
            - 吞吐量等
        - 评测方法有
            - 基准性能测试
            - 压力测试
            - 可靠性测试
    - 系统监视
        - 进行系统监视的方法通常有
            - 通过系统本省提供的命令，如Linux中的ps,top,last等
            - 通过系统记录文件查阅系统特定时间的运行状态
            - 通过集成命令、文件记录、可视化技术，图windows的perform程序

## 补充知识点

- 循环冗余校验码计算
    - 多项式转换为二进制
    - 源二进制后补充对应多项式二进制长度的0
    - 然后进行二进制异或除法
    - 直到除完被除数
    - 将剩下的余数添加到源二进制之后作为校验码部分
