# 系统架构师考试

## 项目及分值

- 选择题，75分
    - 上午考试，75道
- 案例题，75分
    - 下午考试，3道题，实际为5道题，一题必做，后面四选二
- 论文题（论述题），75分
    - 下午考试，4选1论述，300字数摘要+2500字正文论述

## 通过判断

- 三个科目，都需要达到60%及格
- 一般是，上午选择题+案例，时间自由分配
- 下午，论文
- 资格考试，只管过不过，分数无所谓，所以，但求科科过即可

## 案例-考情分析

> 做三道题，一题必做，后面四选二；优先考虑三星内容

> 其实就是，12+4/5做就行

- 题目分布
    - 一题：架构基础知识，***
        - 架构风格
        - 架构评估
    - 二题：软件工程综合知识，***
        - 关系型数据库+结构化
        - 关系型数据库+面向对象
        - 3小问，容易超纲内容
    - 三题：嵌入式开发，*
        - 这个非本专业直接跳过
    - 四题：热门前沿技术，**
        - 比较深入考察
        - redis细节，缓存击穿、雪崩、过滤、限流等
        - aop细节等
    - 五题：WEB系统综合，***
        - 层次式
        - 分布式
        - 微服务
        - 云计算
        - 边缘计算
        - 云原生
- 题型
    - 默写题
        - 纯粹靠理论知识的背诵
    - 线索题
        - 根据线索填空
    - 知识应用题
        - 有可能理论的实际应用或者比较方案

## 论文-考情分析

> 四选一，优先把握能把握的部分，三星优先

- 题目分布
    - 软件架构方面，***
        - 基础
        - 进阶
        - 实战
    - 系统设计综合方面，***
        - 软件工程
        - 结构化分析与设计
        - 面向对象分析与设计
    - 热门技术方面，**
        - 这个可能如果刚好你有实战与理论
        - 那就可以选择试试
    - 前沿新技术方面，*
        - 如果只是粗略的了解过
        - 基本是不行的

## 论文-答题

- 先写正文
- 三章节结构，对应三个论述子问题
    - 项目介绍、架构师职责、论文题目在项目中的应用简介，500字
        - 也就是做的什么项目
        - 技术背景是怎么样的
        - 遇到了什么问题
        - 比较了哪些方案
        - 最终我作为架构师，选择什么方案（点题）
        - 取得了什么样的效果
    - 介绍论文题目的理论知识，1000字
        - 也就是用自己的话，表达理论知识
    - 在自己的项目中的应用及其效果，1000字
        - 一般根据第二问中的进行描述应用及对应的效果
        - 别人家问具体的优化技术，直接答微服务技术，这样就是跑题
        - 而是可以把微服务的其中的技术分开来作为优化技术
- 再根据正文进行摘要
- 关键注意点
    - 题目要求回答什么就回答什么，没要求就不回答，否则可能跑题不得分
    - 要求回答的每一点，进行咬文嚼字，每一点都回答，分段落回答
    - 不为难评分人员，评分人员也不为难你
    - 不要让评分人员在密密麻麻的字里面找每一点的回答
